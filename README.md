## 功能

- 浅色、深色及跟随系统配色，保留 DSH 的字体与字号设置。
- 原有带字财神首页、云纹金边、金元宝品牌与工作区图标，输入框右侧完整展示祥云财神。
- 「今日财运在线」与「功德 +1」彩蛋，点击后 `+1` 从文字位置向上飘。
- 会话内常驻提示词入口，支持标题/简介/正文搜索、标签分类、收藏和最近使用；首页最多展示六张常用卡片。
- 全局库与项目库切换；项目按宿主稳定 ID 隔离，卡片、收藏、最近使用与恢复副本各自保存。
- 主动打开的功德簿，提供累计、里程碑、每日趣味签与确认清零；支持安全共享计数及失败重试。
- 预览后填入、复制正文、另存为，以及带必填字段的变量模板；管理窗口支持新增、编辑、删除与排序。
- 提示词 JSON 备份、导入预览、合并与替换；编辑关闭保护、删除撤销及异常数据恢复。
- 卡片可设置图标或 emoji、八种图标底色、标签、标题、简介、提示词正文及显示位置。
- 自动、完整、紧凑首页布局，随内容宽度与窗口高度收紧；主题外观支持实时预览、保存、取消及恢复默认。
- 插画、装饰强度、财运/功德开关与专注模式，提供朱红鎏金、青玉暖纸、墨蓝沉香三组强调配色。
- 界面文案支持中英文；保留原来的书籍、电脑和气泡装饰文字，中文功德入口恢复原图，动态 +1 仍为文字。

## 安装

当前清单限定 DSH `0.2.1-rc.2`，需要能在侧栏打开「插件」管理页面。本主题面向 DSH 的 Web 界面，包括使用该界面的桌面端，不改变终端界面。

### 在 DSH 中安装

1. 打开侧栏「插件」→「添加插件」。
2. 填写以下地址，点击「安装」：

   ```text
   git+https://github.com/MrGuang123/dsh-theme-caishen.git#v0.2.0
   ```

3. 安装完成后点击「立即启用」。如 DSH 提示需要重启，按提示操作。

推荐使用带版本标签的地址，便于复现问题和回退；直接使用仓库地址会跟随默认分支的内容。

### 使用命令行安装

使用 DSH 的插件命令，安装到你准备使用的 profile：

```bash
dsh plugin --profile web add 'git+https://github.com/MrGuang123/dsh-theme-caishen.git#v0.2.0'
```

将 `web` 换成实际使用的 CLI profile 名称；桌面端用户建议直接从「插件」页面安装。随后按命令提示完成操作，并在 DSH「插件」页面确认本主题已启用。无需自行运行 `pnpm add` 或手工修改 profile 文件。

安装方式以 [DSH 官方插件管理说明](https://github.com/deepseek-ai/deepseek-harness/blob/master/packages/client/ui-plugin-manager/README.zh.md) 为准。GitHub 无法访问时，切换 npm 镜像不能代替 GitHub 下载；也可以下载仓库到本机，再在「添加插件」中填写解压后的插件目录绝对路径。

### 替换 Mac 上的 DSH 图标

1. 退出 DeepSeek Harness（`⌘Q`）。
2. 用 macOS「预览」打开下载的 **PNG 原图**，按 `⌘A` 全选，再按 `⌘C` 拷贝图像。应在「预览」里拷贝图片内容，而不是在访达中直接拷贝 PNG 文件。
3. 在「访达 → 应用程序」中找到实际安装的 `DeepSeek Harness.app`，选中后按 `⌘I` 打开「显示简介」。如果安装在其他目录，请找到对应的 App。
4. 单击简介窗口**左上角、应用名称旁的小图标**，选中后按 `⌘V` 粘贴。不要选中下方「预览」区域的大图。
5. 关闭简介窗口，重新打开 DSH，查看程序坞图标。如果仍显示旧图标，可先退出 DSH，将旧的程序坞快捷方式移除，再把「应用程序」中的 DSH 拖回程序坞。

操作方式参考 [Apple 自定义文件与文件夹图标说明](https://support.apple.com/zh-cn/guide/mac-help/mchlp2313/mac)。无需替换 App 包内部的文件。

### 恢复原图标

退出 DSH，重新打开 `DeepSeek Harness.app` 的「显示简介」，选中左上角的小图标，选择「编辑 → 剪切」（`⌘X`），然后重新打开 DSH。

这项设置与主题的启用、停用独立；卸载主题不会自动恢复应用图标。DSH 升级或重新安装后，如图标恢复原样，按上述步骤重新设置即可。

## 调整主题外观

打开宿主「设置」，在左侧选择「主题外观」。外观设置不占输入工具栏，也不额外打开一层弹窗。

- **首页布局**：自动模式按内容容器宽度收紧，展开侧栏后也能适应；完整模式显示插画与文案；紧凑模式缩为短横幅。窄窗口和低高度会进一步收紧布局，避免留下隐藏插画后的大块空白。
- **装饰强度**：完整、适度、关闭；默认适度，减少重复徽章与阴影。关闭装饰会隐藏纸纹和工作区、账户的装饰替换。
- **插画和彩蛋**：可分别关闭首页插画，以及财运/功德按钮。开关不清除功德计数或提示词数据。
- **专注模式**：临时采用紧凑布局，隐藏横幅、插画、装饰和彩蛋，保留提示词、输入与发送操作；关闭后恢复此前的具体选项。
- **强调配色**：朱红鎏金、青玉暖纸、墨蓝沉香；保留宿主的浅色、深色及跟随系统机制，不修改系统外观。

所有调整先实时预览，点击「保存外观」后才写入本机；点击「取消」会恢复已保存设置；离开主题页或关闭宿主设置会放弃未保存预览。「恢复默认预览」也需要保存才持久生效。其他窗口已修改、存储异常或写入失败时会明确提示，避免覆盖；点击「取消」可以重新读取最新保存设置。外观偏好单独保存在本地，不包含会话、提示词正文或变量答案。

控件具有键盘焦点和至少 36px 的主要点击区域，弹窗可滚动；尊重系统减少动态效果偏好。新增中文与英文文案同步，既有用户卡片不会随语言切换重写。

## 使用提示词库

默认提供八张研发卡片；首页最多展示六张，优先采用收藏、最近使用，再按原顺序补足。全部卡片可从输入框旁的「提示词」或首页「查看全部与管理」打开：

| 卡片 | 用途 |
| --- | --- |
| 排查并修复问题 | 结合现象与报错定位根因，完成修复并验证 |
| 实现一个需求 | 结合现有实现开发功能，处理边界情况并验证 |
| 审查当前改动 | 默认只分析，检查功能错误、遗漏和回归风险 |
| 补充关键测试 | 针对功能或缺陷补充有价值的测试 |
| 理解一段代码 | 默认只分析，说明入口、调用关系与关键约定 |
| 局部重构 | 保持现有行为，改善指定范围内的实现 |
| 定位性能瓶颈 | 基于具体慢点和测量依据定位瓶颈 |
| 总结本次改动 | 默认只生成文字，整理修改内容与验证结果 |

点击卡片只会将提示词填入输入框，**不会自动发送**；请补充问题现象、需求或代码范围，再按需修改和发送。

输入框已有内容时，会尝试在插入位置加入提示词；插入失败会保留原输入并提示重试，不会回退为整段替换。

- 在完整库搜索标题、简介或正文，并组合「收藏」「最近使用」与标签分类；分类使用卡片现有的「标签」，不改写正文或保存顺序。
- 选择结果后先预览正文，再「填入当前输入框」；「复制正文」复制最终文本；「另存为新卡片」创建独立 ID，修改副本不影响原卡片。
- 「管理卡片」中可新增、排序、备份与导入；「研发模板」包含八种研发任务和一张需求拆解变量模板，选择后编辑并保存才加入库。
- 编辑卡片时勾选「启用变量模板」，使用 `{{需求}}`、`{{范围}}`、`{{验收标准}}` 等占位符。每个不同字段均必填，最多 16 项；重复字段共用答案，`\{{示例}}` 保留为文字。未勾选时，双花括号也按普通正文使用。
- 变量答案在本次弹窗中保留，切换卡片后可以返回继续填；最终正文预览通过后才能填入或复制，正文上限为 12000 字符。关闭有变量答案的窗口时会询问是否放弃。
- 库内按 `/` 聚焦搜索，从搜索框按 Enter 或向下方向键进入结果，再用上下方向键、Home/End 和 Enter 选择；Esc 关闭当前弹窗，关闭或填入后返回输入框。可在宿主「编辑快捷键」为「打开提示词库」绑定按键，默认不占用组合键。
- 卡片上的「编辑」可修改字段和位置；删除、排序在「管理卡片」中操作。编辑或排序未保存时，关闭、取消、Esc 与遮罩均提供放弃确认，失败保留草稿。
- 删除后可依次「撤销删除」，恢复完整卡片及原位置。当前首页或库窗口关闭、刷新或清除撤销记录后，记录消失；管理与预览之间切换保留撤销记录。
- 图标支持预设图案或单个 emoji；底色可选八种。收藏和最近使用仅保存本地卡片 ID，最近使用最多 20 项，填入或成功复制会更新记录。

弹窗打开期间若输入内容或版本发生变化，填入会失败并提示重新检查草稿；关闭后重新打开即可捕获新的插入位置，任何情况都不会自动发送。

![提示词排序弹窗](https://raw.githubusercontent.com/MrGuang123/dsh-theme-caishen/main/assets/previews/documentation/prompt-sort.png)

自定义卡片、顺序与功德计数保存在当前 Web 界面来源的浏览器本地存储（`localStorage`），不会由本插件上传或云同步。不同浏览器、设备或访问地址可能使用不同的数据；清理网站数据会删除它们。升级或切换环境前，请通过「备份与导入」导出 JSON 文件。

### 全局库与项目库

在完整提示词库顶部的「提示词范围」切换。全局库继续使用旧数据；项目库初始为空，可从「研发模板」添加，或从全局库导出后切换到项目库导入。首页快捷卡片仍采用全局库，项目卡片通过完整库访问。

项目归属读取 DSH 的稳定工作区 ID，同名目录不会混为一库；窗口显示当前路径以便区分。无法确定当前会话归属时，项目选项禁用，全局库可照常使用。编辑或变量答案未保存时切换范围需要确认；切换会话或项目会关闭旧窗口，避免填入错误的输入框。

卡片、收藏、最近使用、导入/导出、重置和撤销均只作用于当前所选库。项目重置为空，不复制全局默认卡片。删除后重新创建工作区可能取得新 ID；换设备或访问地址也不会自动映射旧项目，请在原范围导出，再到目标范围导入。

### 备份与导入

在「提示词」→「管理卡片」中打开「备份与导入」：

1. 「导出当前提示词」请求浏览器下载带版本的 JSON，包含卡片正文、图标、底色和顺序。存在变量模板时使用版本 2 保存启用标记，否则仍为版本 1；收藏与最近使用属于本机偏好，不纳入卡片备份；请查看浏览器下载记录。空列表也可以备份。
2. 选择 JSON 文件或粘贴内容，点击「校验并预览」。支持本主题版本 1、版本 2 备份，以及旧版纯卡片数组；文件上限为 16 MiB、卡片上限为 128 张。
3. 「合并」保留当前列表和同 ID 卡片，只追加新 ID，并预览重复、新增和最终数量；「替换」采用备份顺序，需要再次确认，空备份可以明确清空列表。
4. 只有确认导入才写入。取消、校验失败或存储失败不会改变原列表；如期间其他窗口修改了数据，会要求重新检查更新后的预览。

备份只包含当前选定库的卡片，不包含其他项目、范围身份、收藏或功德。跨范围转移前先确认顶部范围；需要保存多个项目时分别导出。

### 异常数据恢复

本地数据损坏时，页面保留异常原文，显示默认模板或上次有效列表，并暂停普通保存和导入。可以先「导出异常原文」，或在「备份与导入」中导出当前可见列表；两者用途不同，异常原文可能不是可直接导入的有效 JSON。

「重新读取」可检查存储是否已恢复；确认「重置为默认模板」前，会先保存一份本地异常恢复副本。副本写入失败或数据已变化时不会覆盖原值。恢复副本只保留最近一次，可在「备份与导入」中导出，清理网站数据也会删除它。空间不足或存储不可用时，编辑草稿会保留，可先导出可见数据再重试。

同时编辑或删除同一张卡片时，如果它已在其他窗口改变，会保留当前草稿并提示冲突，避免覆盖别人的修改。

**已有保存的提示词库不会被新的默认卡片覆盖**，包括原有卡片内容、顺序和主动清空的列表。升级后可通过「研发模板」按需添加新的研发卡片。

## 功德簿

点击功德按钮旁的「功德簿」，查看本机累计、1/10/100/1000 点里程碑与当天的趣味签。签文按本地日历日期选取，不是随机预测，不读取会话、工时或项目成果。「重置功德」需要再次确认；异常计数会先保存最近一次恢复副本，再清零。

支持 Web Locks 的同来源窗口会串行合并功德更新。写入失败时新增保留在当前窗口，可在功德簿重试；刷新前未保存的部分可能丢失。环境不支持共享锁时，新增仅保留在当前窗口并明确提示，不覆盖持久计数。旧版客户端不使用共享锁，避免与新版同时操作同一来源。

在「主题外观」关闭财运与功德彩蛋，或开启专注模式，可以隐藏按钮与功德簿入口，原累计保留。功德、里程碑与签文均为可关闭的装饰，不表示真实收益、效率或项目统计。

## 更新、停用和卸载

- **更新**：查看新版本说明，在「插件」页面卸载旧包，再用发布说明中的新标签地址重新安装。主题不提供自动更新。
- **暂时停用**：关闭整个「财神打工版」组合包，按 DSH 提示刷新或重启，恢复内置界面。请不要只关闭其中的 `theme-caishen` 组件行，否则组合包中关闭官方品牌的补丁仍会生效。
- **卸载**：在「插件」页面移除 `dsh-theme-caishen`。插件不主动清理浏览器中的自定义卡片与功德计数。

## 跟随系统时为什么白天也可能显示深色

「跟随系统」由 DSH 读取系统当前的实际外观，不按白天或夜晚直接判断。本主题仅提供浅色与深色配色，不修改系统外观或 DSH 的外观设置。

macOS 27 的「自动」外观会参考夜览（Night Shift）日程；未设置日程时参考日出日落，并且至少空闲一分钟才切换。系统当前仍处于深色时，DSH 和本主题随之显示深色属于正常表现。详见 [Apple 外观设置说明](https://support.apple.com/en-ie/guide/mac-help/mchlp1225/27/mac/27)。

如希望 DSH 始终显示浅色，可在 DSH「设置 → 外观」选择「浅色」。验证系统同步时，可暂时将 macOS「系统设置 → 外观」改为「浅色」，同时让 DSH 保持「跟随系统」；界面应随之变浅。若系统已经明确切为浅色而 DSH 仍深色，请在 Issues 中附上系统与 DSH 的外观状态及版本，继续定位宿主同步问题。

## 兼容性与数据

- 这是独立第三方主题，不是 DeepSeek 官方主题。建议避免同时启用多个会覆盖品牌、颜色或相同界面插槽的主题。
- 配色与适配目标为 DSH `0.2.1-rc.2`，`engines.dsh` 限定该版本；其他版本可能被插件管理器拒绝安装，需验证后再扩大范围。发布前验收方法见 [发布说明](https://github.com/MrGuang123/dsh-theme-caishen/blob/main/docs/RELEASING.md)。
- 部分装饰样式依赖 DSH 的界面结构，DSH 升级后可能需要调整。遇到布局异常时可先停用主题，再在 [Issues](https://github.com/MrGuang123/dsh-theme-caishen/issues) 提供 DSH 版本、操作系统、深浅色和窗口大小。
- 插件运行时从自身目录提供图片资源，不引入额外远程图片或统计服务。宿主侧注册统一素材路由、旧 URL 兼容别名及独立样式路由；提示词只在你点击卡片时写入宿主输入框。
- 插画和财运、功德均为装饰，不读取实际项目成本或财务数据。首页恢复原有带字场景；电脑内的金额、效率与书名均为插画装饰，不连接实际账户或项目统计。
