## 完成判定

第二阶段完成应同时满足：四项数据保护需求已实现，源码与构建产物一致，离线、独立浏览器及打包检查通过，文档与状态同步；主卡片格式不变，新增异常恢复副本有明确生命周期。第三阶段还须完成 PROMPT-001 至 PROMPT-004，验证旧数据兼容、模板备份往返、当前会话输入安全和完整键盘路径。第四阶段还须验证预览不写入、取消回滚与保存保护，以及容器宽度、窄窗/低高度、200% 字号和减少动态效果；第五阶段验证稳定 ID 项目隔离、范围内恢复与备份、功德并发与降级；第六阶段补真实宿主生命周期、可复现预览和探索决策。真实 DSH 验收若未执行，应记录为待验证，不能用离线检查或独立截图替代。

后续每项需求完成时，应记录对应实现、验证结果和剩余限制，再将状态从待实施改为已完成；仅创建文件、写出计划或通过静态检查不构成功能完成。

第三阶段验收说明：常驻入口复用 `conversation.input.right`，读取宿主 `useInput`；分类复用卡片标签；收藏和最近使用独立保存 ID；变量模板由可选 `template: true` 显式启用。备份支持版本 1/2，旧卡片无须迁移。键盘打开命令通过可选宿主 shortcuts 服务注册，默认无键位，用户在宿主设置绑定，冲突由宿主校验。独立浏览器验收不替代实际 DSH 安装验证，详见 [验证记录](VALIDATION.md)。

第四阶段原交付使用输入侧外观入口；按用户视觉反馈，现迁到正式 `settings.section` 内嵌设置页，输入栏不再显示外观按钮。`appearance:v1` 单独保存外观选项，取消恢复已保存状态，专注模式不改写底层选择。原书籍、电脑文字、手绘气泡及功德图片按钮已恢复，配套功德簿入口与顶部对齐已修复；无字场景仍保留兼容路径，图片装饰文字不作业务统计。对比度检查覆盖代表性色对，不等同于完整 WCAG/读屏认证；实际宿主安装仍另行验收。

第五、六阶段验收说明：项目身份由宿主 `useWorkspaces` 的稳定 ID 与会话归属取得；项目为空库且独立保存，不迁移全局库。功德簿提供累计、派生里程碑、每日趣味签和确认重置；Web Locks 合并当前客户端窗口，缺席时只保留本窗口新增。`adapter/host.cjs` 与 `host-adapter.css` 集中宿主契约。DSH `0.2.1-rc.2` 真实打包安装、项目隔离、输入、多窗功德、整包启停与卸载已验证；独立浏览器补窄/低窗、浅深色、中英文与 200% 字号。成本/Token/效率/同步的证据、边界与下一步见 [探索评估](EXPLORATION.md)，不把评估等同于上线这些功能。
