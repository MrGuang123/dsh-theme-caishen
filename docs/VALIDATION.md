# 0.1.0 发布准备验证

验证日期：2026-10-19。宿主环境为 macOS，已安装 DSH `0.2.1-rc.2`；源码检查使用 Node.js `22.17.0`，实际安装使用 DSH 自带 CLI 与运行时。

## 已通过

- `npm run check:release`：语法、122 个配色 token、100 个中英文文案键、9 个插槽、组件清理，以及提示词校验、增删改、排序、持久化和存储失败处理。
- 实际 `npm pack` 产物：运行入口、DSH 补丁、元数据、图标和全部 15 处浏览器素材引用完整；不包含临时输出、系统杂项或个人配置。
- 将安装包解压到临时目录，验证全部素材读取、`HEAD`、只读方法约束、缺失文件和非法路径处理；宿主路由可随插件卸载清理。
- 使用独立的 `DSH_HOME` 与测试 profile，通过真实 DSH CLI 安装 `.tgz`；识别版本为 `0.1.0`，自动加入组合包选择。
- DSH 配置组合结果包含主题行，并关闭官方品牌行；停用整个组合包后主题行消失，官方品牌恢复；重新启用可恢复主题行。
- CLI 卸载后，测试 profile 的主题依赖、组合包选择与安装目录被移除，官方品牌恢复。
- 安装后的宿主入口可以导入并导出 `apply`。上述安装与卸载没有修改日常使用的 DSH profile。

安装验证完成后，仅继续修订公开文档；运行代码和素材未改变。
