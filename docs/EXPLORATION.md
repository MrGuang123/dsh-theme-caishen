# 可选统计与同步评估

日期：2026-10-23。对应 EXPLORE-001；结论为完成评估，另立功能后实施，不给核心主题增加统计服务、账户权限或网络请求。

本轮只读核对已安装 DSH `0.2.1-rc.2` 内的官方 `@deepseek-ai/dsh-session-stats/README.zh.md` 及当前会话、工作区接口。以下属于该版本的能力边界，不声明未来版本相同。

| 方向 | 已确认的数据或基础 | 口径、权限与价值 | 决定 |
| --- | --- | --- | --- |
| 会话 Token 与耗时 | 可选 `sessionStats` 全日志投影提供轮次、关闭步骤、模型/工具墙钟时间、首 Token、解码时间及输出 Token | 投影可能缺席；缺席显示“不可用”，不能当作 0。`decodeTokens` 只覆盖符合投影守卫的提供方输出报告，不等于输入加输出总量。关闭步骤包括失败、取消等，不能称为完成任务数 | 后续独立只读“会话诊断”候选，优先复用宿主现有统计条；先验证公开客户端投影 seam 与不同提供方数据完整性 |
| 实际成本 | 当前主题没有结算账单、账户折扣、缓存价、币种或可复核价格快照 | Token 乘示例单价不能表示实际扣费。需要权威账单或明确标注的估算口径；新增账户接入必须单独授权 | 暂不实现金额；日后需独立价格来源、时间、币种、缓存/推理用量和缺失数据规范 |
| 效率或工作成就 | 宿主轮次、步骤和耗时描述交互，不描述验收结果或人工工时 | 缺少任务完成证据、基线和人工投入，不能推导节省时间、生产率或真实收益。读取代码/工单/提交还涉及额外来源和权限 | 不推导效率分数；若做工作记录，先定义用户主动确认的完成条件及数据删除规则 |
| 功德里程碑 | 本机点击累计，旧数值 key 可兼容；每日趣味签由本地日期决定 | 不读取项目日志，不授予真实工作成就；可关闭且不打断工作 | 本轮仅交付明确说明为装饰的功德簿，与会话业务统计完全分开 |
| 提示词同步 | 现有版本化 JSON 备份可手工跨设备转移，全局与项目库各自导出 | 提示词可能含私密信息；浏览器 origin 和宿主工作区 ID 不跨设备通用。未指定服务端、身份认证、加密、冲突及删除策略 | 本轮保留手工导入/导出，不自动上传。可选同步另开需求、默认关闭并明确目标范围映射 |

后续若启动独立“会话诊断”阶段，按以下步骤推进：

1. 确认宿主公开读取接口和数据版本；建立无投影、取消、失败、压缩、分页及缺少 usage 的样本。
2. 编写字段字典：来源、时间区间、单位、缺失状态与聚合方式；先交付会话内只读数据，不跨项目排名。
3. 设计主动打开的诊断面板，解释数据范围，不读取额外凭据，不发起模型请求；缺少接口时完整降级。
4. 在目标 DSH 版本隔离验收数据与宿主统计一致后，再单独评审成本估算或工作记录需求。

后续若启动可选同步，先选择用户明确指定的服务，再单独确定身份授权、最小上传字段、传输与静态加密、项目映射、双向冲突预览、离线重试、撤销与远端删除。验收必须证明未开启时零上传，冲突时不静默覆盖，停止同步后可清除远端数据。以上为未来实施计划，不是当前已交付功能。
